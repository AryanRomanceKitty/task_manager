# Task Manager - README

A clean and simple command-line to-do list app built with pure Python. No external libraries, no complicated setup—just a beginner-friendly script that actually feels nice to use.

## Features
- Add one or more tasks at startup (or skip with 0)  
- Add, update, or delete tasks anytime via a clear menu  
- View your full task list with numbered entries and neat borders  
- Input validation everywhere (wrong numbers, empty tasks, etc. won’t crash the program)  
- Friendly success/error messages  
- Fully self-contained—runs on any system with Python 3

## How to Run
1. Make sure Python 3 is installed on your computer  
2. Save the code as `better_app.py`  
3. Open your terminal/command prompt and navigate to the folder  
4. Run the script:  
```bash
python better_app.py
```

That’s it—you’ll see the welcome screen instantly.

## How It Works
First, it asks how many tasks you want to add right away.  
  After that, a menu with options 1–5 lets you manage everything.
   Tasks are stored in a simple Python list while the program is running.

## Why This Version Is Nice
 Clean formatting using “=” borders (makes it look way better than plain text)  
 Prevents common mistakes like empty tasks or invalid numbers  
 Clear feedback after every action  
 Easy to read and modify—perfect for learning or extending
