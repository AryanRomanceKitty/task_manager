## Problem Statement  
I needed a super simple to-do list that just works in the terminal — no sign-up, no internet, no extra stuff to install. Most apps are too complicated for quick practice, so I built this tiny task manager that actually feels nice to use.

## Scope of the Project  
Just a basic command-line app made with pure Python (zero external libraries).  
What it does: add, update, delete, and show tasks.  
What it doesn’t do: save tasks after closing, GUI, due dates, etc. (kept it simple on purpose)

## Target Users  
 First-year CS students 
 Anyone learning Python basics  
 People who just want a quick offline to-do list  

## High-Level Features  
 Add a bunch of tasks right when you start  
 Easy menu (1–5) to manage everything  
 Update or delete any task by its number  
 Looks clean with those === borders  
 Won’t crash even if you type wrong stuff  
 Doesn’t let you add empty tasks
